Cross TX and RX (module TX to host RX), share ground, and power the module from a supply that matches the supply voltage in the specification table. See [Wiring and power](../get-started/wiring-and-power.md).

## Protocol summary

- Data frame: 4 bytes, `5C <dist_lo> <dist_hi> <check>`, free-running.
- Default baud: 460800 bps, 8 data bits, 1 stop bit, no parity.
- Distance: 2 bytes, little-endian, unit **millimetres**. The VB series reports millimetres and the H series centimetres, so `5C 02 11 EC` is 4.354 m on a VB module and 43.54 m on an H module.
- Out-of-range marker: the module outputs 65535 when there is no valid target. Treat it as no target, not as a distance.
- Checksum: bitwise inverse of the 8-bit sum of all bytes between the header and the check byte.

| Command | Request frame |
|---|---|
| Start ranging | `5A 0A 02 02 00 F1` |
| Stop ranging | `5A 0A 02 00 00 F3` |

The full frame description is in [Family B protocol](../protocols/family-b-5c.md). Try it without installing anything in the [browser serial monitor](../tools/serial-monitor.mdx).

## Code examples

<Tabs groupId="lang">
<TabItem value="python" label="Python" default>

```bash
pip install erdi-lrf   # PyPI, MIT
erdi-lrf --port /dev/ttyUSB0 --model LRF10VB stream --count 20
```

```python
from erdi_lrf import ErdiLRF

# COM3 on Windows, /dev/ttyUSB0 or /dev/serial0 on Linux
with ErdiLRF("/dev/ttyUSB0", "LRF10VB") as lrf:
    for r in lrf.stream():
        print("out of range" if r.out_of_range else f"{r.metres:.3f} m", "raw", r.raw)
```

## Known issues

- UART logic level is not stated as a separate field for most models. Supply voltage is not the UART voltage: check the module's TX level against your host before wiring, or ask us.
