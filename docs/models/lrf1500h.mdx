## Pinout and wiring

| PIN | Definition / Wire Color | User Interface |
|---|---|---|
| 1 | 9-36V (Red) | External Power + |
| 2 | Power GND (Black) | External Power - |
| 3 | Port GND (Yellow) | GND |
| 4 | TX (Green) | RX |
| 5 | RX (Blue) | TX |

Cross TX and RX (module TX to host RX), share ground, and power the module from a supply that matches the supply voltage in the specification table. See [Wiring and power](../get-started/wiring-and-power.md).

## Protocol summary

- Data frame: 5 bytes, `5C <dist_lo> <dist_mid> <dist_hi> <check>`, free-running.
- Default baud: 460800 bps, 8 data bits, 1 stop bit, no parity.
- Distance: 3 bytes, little-endian, unit **centimetres**. The VB series reports millimetres and the H series centimetres, so `5C 02 11 EC` is 4.354 m on a VB module and 43.54 m on an H module.
- Out-of-range marker: the module outputs 16777215 when there is no valid target. Treat it as no target, not as a distance.
- Checksum: bitwise inverse of the 8-bit sum of all bytes between the header and the check byte.

The full frame description is in [Family B protocol](../protocols/family-b-5c.md). Try it without installing anything in the [browser serial monitor](../tools/serial-monitor.mdx).


```python
from erdi_lrf import ErdiLRF

# COM3 on Windows, /dev/ttyUSB0 or /dev/serial0 on Linux
with ErdiLRF("/dev/ttyUSB0", "LRF1500H") as lrf:
    for r in lrf.stream():
        print("out of range" if r.out_of_range else f"{r.metres:.3f} m", "raw", r.raw)
```

<TabItem value="arduino" label="Arduino">

```cpp
#include <ErdiLRF.h>

ErdiLRF lrf(Serial1, ERDI_LRF1500H);

void setup() {
  Serial.begin(115200);
  Serial1.begin(erdiDefaultBaud(ERDI_LRF1500H));   // 460800 baud; ESP32: Serial1.begin(baud, SERIAL_8N1, RX_PIN, TX_PIN)
  lrf.setTimeout(1000);
}

void loop() {
  ErdiMeasurement m;
  if (lrf.measure(&m) == ERDI_OK) {
    Serial.println(m.metres, 3);
  }
  delay(200);
}
```

## Known issues

- The datasheet's example frame `5C 02 11 03 EC` does not satisfy its own checksum rule (the rule gives `E9`). The driver and the serial monitor use the rule.
- The datasheet writes the out-of-range marker as `0xFFFF (16777215)`. With a 3-byte distance field the marker is 16777215.
- UART logic level is not stated as a separate field for most models. Supply voltage is not the UART voltage: check the module's TX level against your host before wiring, or ask us.
