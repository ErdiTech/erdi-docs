If you want to bench-test before designing a module in, the evaluation kit on the main site is the quickest way to get a module, a cable and the documents together: [erdilrf.com/evaluation-kit](https://erdilrf.com/evaluation-kit/).

Before you order, read the [evaluation checklist](../guides/evaluation-checklist.md). It lists what to measure on the bench so that the first week of testing answers the questions that matter for your product.

For a model not listed in the kit, or for a question about the protocol of a model without a public document, write to tommy@erdimail.com.
