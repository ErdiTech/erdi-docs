## 2026-11-13, version 1

- First release of this site.
- Model pages for the 22 models with a published protocol, generated from the ERDI product database.
- Protocol pages and guides synchronised from the erdi-lrf-drivers repository.
- Platform pages: ArduPilot (Lua route), PX4, ROS 2, ESPHome, Arduino, Python and Raspberry Pi, STM32, MicroPython.
- Compatibility matrix with one Verified class of entry (ArduPilot Lua in SITL).
- Browser serial monitor with decoder tests.

Driver releases: [erdi-lrf on PyPI](https://pypi.org/project/erdi-lrf/#history), [erdi-lrf-drivers](https://github.com/ErdiTech/erdi-lrf-drivers/commits/main).
