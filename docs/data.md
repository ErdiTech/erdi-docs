description: "Open datasets about laser rangefinder modules published by ERDI: the module database on GitHub and the open-data page on erdilrf.com."
---

- [Laser rangefinder module database](https://github.com/ErdiTech/laser-rangefinder-module-database): an open table of laser rangefinder and LiDAR distance modules with range, accuracy, interface and weight.
- [erdilrf.com/open-data](https://erdilrf.com/open-data/): the same data with citation information and downloads.
- [awesome-laser-rangefinder](https://github.com/ErdiTech/awesome-laser-rangefinder): a curated list of drivers, integrations and standards.
